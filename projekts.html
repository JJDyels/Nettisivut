Projektit

Tässä osiossa esittelen joitakin projekteja, joita olen toteuttanut opintojeni ja harrastusteni aikana. Projektit kattavat erilaisia teknologioita ja ohjelmointikieliä, ja ne kuvaavat osaamistani sekä kykyäni soveltaa oppimaani käytännön tilanteissa.

Linux farmi

Tässä projektissa toteutin Oracle VM -ympäristöön Linux-pohjaisen palvelininfrastruktuurin, joka koostui yhdestä Debian Desktop -työasemasta, yhdestä Debian Server -palvelimesta sekä yhdestä Alpine Linux -palvelimesta. Projektin tavoitteena oli rakentaa turvallinen etähallintaympäristö, jossa Debian Desktop toimi hallintakoneena ja palvelimia hallittiin SSH-yhteyksien kautta.

Ympäristöön määritettiin normaalikäyttäjille sudo-oikeudet, poistettiin SSH-salasanakirjautuminen käytöstä ja otettiin käyttöön Microsoft Authenticatoriin perustuva monivaiheinen tunnistautuminen (MFA). Lisäksi palvelimien tietoturvaa vahvistettiin Fail2ban-ratkaisulla, joka suojaa palvelimia rajoittamalla toistuvia kirjautumisyrityksiä.

SQL verkkokauppa

Tässä projektissa suunnittelin ja toteutin PostgreSQL-tietokannan yksinkertaista verkkokauppaa varten. Tietokanta koostuu kuudesta taulusta: customers, products, orders, orderitems, shoppingcart ja cartitems, joiden avulla voidaan hallita asiakastietoja, tuotteita, varastosaldoja, ostoskoreja sekä toteutuneita tilauksia.

Projektin aikana toteutin erilaisia SQL-kyselyitä ja raportteja, kuten ostoskorien sisältöjen tarkastelua, tilausmääriä, myydyimpien tuotteiden seurantaa sekä aikaväleihin perustuvia raportteja. Yksi mielenkiintoisimmista ominaisuuksista oli trigger-funktio, joka päivittää automaattisesti tilausten kokonaishinnan (total_price) aina, kun tilausrivejä lisätään, muokataan tai poistetaan.

Vaikka tietokanta on tarkoituksella yksinkertainen ja suunniteltu SQL-perusteiden harjoitteluun, projekti tarjosi käytännön kokemusta relaatiotietokantojen suunnittelusta, SQL-kyselyistä, triggerien hyödyntämisestä sekä tietokannan rakenteen kehittämisestä tulevia laajennuksia varten.
